# 온도옷장 · Ondo Wardrobe

내가 가진 옷으로 오늘의 날씨와 일정에 맞는 코디를 고르는 웹 프로토타입입니다.

## 빠른 실행

Python 3이 설치된 환경에서 이 폴더를 열고 실행합니다.

```bash
python -m http.server 8080
```

브라우저에서 http://localhost:8080 을 엽니다.

별도 패키지 설치나 빌드 과정은 없습니다. 외부 날씨 API, Pinterest 위젯, 글꼴 등은 인터넷 연결이 필요합니다. 팀원마다 같은 실행 주소를 사용하면 로컬 데이터 관리가 편합니다.

## 프로젝트 구조

```text
ondo-wardrobe/
├── index.html
├── assets/
│   ├── css/              # 기존 화면과 기능별 스타일
│   └── js/               # 기능별 스크립트
├── README.md
└── .gitignore
```

스크립트는 index.html에 선언된 순서대로 실행합니다. 기존 단일 HTML의 기능을 유지하면서 파일을 분리한 구조이며, 공용 상태를 참조하는 스크립트가 있으므로 로딩 순서를 유지하세요.

### 주요 코드 위치

- weather.js — 날씨 조회, 장소·민감도와 기본 코디 안내
- wardrobe.js — 옷장 저장, 사진·정보 편집, 코디 추천, 개인화
- mannequin.js — 보류 중인 3D 코드
- body-controls.js — 키·몸무게 UI 보조 코드
- pinterest.js — Pinterest 핀·보드 링크 등록
- inspiration.js — 참고 사진 저장과 스타일 연결
- navigation.js — 오늘의 코디·내 옷장 탭, 분류 필터, 사진 미리보기
- personalization.js — 자주 입는 옷과 피드백 UI
- upload-guide.js — 사진 등록 단계와 안내 UI

3D와 체형 UI는 현재 숨겨져 있으며 서비스 핵심 흐름에 사용하지 않습니다.

## 사용 흐름

1. 내 옷장 탭에서 옷 한 벌의 사진을 선택합니다.
2. 미리보기를 확인하고 이름, 종류, 색상, 보온성, 스타일을 입력합니다.
3. 옷장에 저장합니다.
4. 옷 카드에서 사진·정보 수정, 착용 상태, 즐겨찾기, 고정 여부를 설정합니다.
5. 오늘의 코디에서 날씨·장소를 선택하고 보유 의류 조합을 추천받습니다.
6. 추천 거절 이유 또는 실제 착용 후 체감을 남깁니다.

사진 등록은 JPG·PNG·WebP, 최대 15MB를 안내합니다. 저장 시 긴 변 최대 700px의 JPEG로 축소됩니다. 편집 화면에서 사진 교체, 90도 회전과 옷 정보 수정이 가능합니다.

## 구현 기능

- 옷 사진 등록·미리보기·로컬 저장·삭제
- 등록한 사진 교체·회전 및 옷 정보 수정
- 상의·바지·스커트·겉옷·신발 분류
- 착용 가능·세탁 중·건조 중·수선 중 상태
- 한 벌 고정 후 나머지 조합 추천
- 자주 입는 옷 최대 10벌 선택과 추천 범위 제한
- 안 입는 이유 기록과 해당 옷 활용 추천
- 날씨·장소·선호 스타일 기반 추천
- 추천 거절 이력과 유사 기온의 체감 피드백 반영
- 참고 이미지 업로드와 Pinterest 공식 링크 임베드

## 현재 추천 방식

이미지의 종류와 스타일은 사용자가 직접 입력합니다.

- 스타일 일치에 3점, 보온성 일치에 2점을 부여합니다.
- 같은 장소에서 거절한 횟수에 따라 해당 옷의 순위를 낮춥니다.
- 착용 불가능한 옷과 사이즈·착용감 문제가 표시된 옷은 제외합니다.
- 비에는 방수 신발, 눈에는 방수·접지 조건을 적용합니다.
- 고정한 옷도 착용 가능 조건과 날씨 조건을 확인합니다.
- 비슷한 기온의 최근 체감 기록을 사용해 보온 기준을 조정합니다.

현재 방식은 규칙 기반입니다. 거절 사유는 저장되지만 각 사유별 세밀한 모델 학습은 아직 구현하지 않았습니다.

## 데이터 저장

옷 사진·정보는 IndexedDB의 weather-wardrobe 데이터베이스 안에 저장합니다. 참고 사진은 wardrobe-inspiration에 저장합니다. 개인화 기록과 Pinterest 링크는 localStorage에 저장합니다.

데이터는 브라우저와 사이트 주소에 귀속됩니다. 이전 file 주소 또는 다른 포트에서 저장한 옷장이 새 주소에 자동으로 나타나지는 않습니다. GitLab에 올리는 소스에는 브라우저의 사진·개인 기록이 포함되지 않습니다.

### 옷 데이터

```js
{
  id, name, photo,
  type,       // top, bottom, skirt, outer, shoes
  color,      // HEX
  warm,       // light, medium, warm
  style,      // minimal, casual, formal, sport
  water, grip,
  state,      // ready, laundry, drying, repair
  favorite, unusedReason, lastWorn
}
```

예전 데이터에 state가 없으면 착용 가능으로 처리합니다.

### 협의할 API 초안

아래 경로는 아직 서버에 구현되지 않은 제안입니다.

```text
POST   /api/images/analyze     사진 분석 → 종류·색상·신뢰도
GET    /api/clothes            내 옷 목록
POST   /api/clothes            옷 등록
PATCH  /api/clothes/:id        정보·사진·상태 수정
DELETE /api/clothes/:id        옷 삭제
POST   /api/outfits/recommend  날씨·장소·고정 옷 → 옷 ID 목록·이유
POST   /api/feedback           추천 거절·착용 체감 저장
```

기존 IndexedDB 호출을 교체할 때 로딩·실패 처리와 기존 데이터 이전 정책을 함께 결정하세요. 인증정보와 비밀 키는 서버 환경변수로 관리하고 저장소에 커밋하지 않습니다.

## 이번 MVP의 범위

사진 기반 AI 자동 분류, 서버 저장·인증, Pinterest 계정 동기화, 실제 핏 예측은 추가 개발 항목입니다. 현재 Pinterest 기능은 직접 등록한 공개 링크를 공식 위젯으로 표시합니다.

사진 크롭과 배경 제거는 아직 구현되지 않았습니다. 현재 제공되는 사진 편집은 교체와 회전입니다.

## 확인할 시나리오

- 사진 선택 후 미리보기와 옷 등록
- 새로고침 후 저장된 옷 복원

JavaScript 문법 검사를 수행했습니다. 새 사진 편집 화면의 전체 브라우저 검증은 추가로 필요합니다.

## GitLab 공유

GitLab에서 빈 프로젝트를 만든 뒤 이 폴더를 저장소 루트로 올립니다.

```bash
git init
git add .
git commit -m "Initial Ondo Wardrobe MVP"
git branch -M main
git remote add origin <GitLab에서 복사한 저장소 주소>
git push -u origin main
```

프로젝트 URL이 정해지면 위 원격 주소를 대체합니다. 현재 원격 저장소 연결·업로드는 수행하지 않았습니다.

## 시작 화면과 게스트 체험
- 첫 방문에 로그인 또는 게스트를 선택합니다.
- 로그인은 서버 인증 없는 데모이며 기존 브라우저 옷장을 사용합니다.
- 게스트는 코디 기준·키, 스타일, 상의, 하의, 겉옷, 색감, 요약의 7단계를 거칩니다.
- 게스트 데이터는 메모리에서만 처리하며 새로고침하면 초기화됩니다. 기존 IndexedDB 옷장을 읽거나 변경하지 않습니다.
- 스타일은 추천 점수에 반영됩니다. 의류 종류와 색감은 등록 참고용이며 키 기반 핏 예측은 제공하지 않습니다.
